# llama.cpp for legacy devices
Set of patches and workflows to build llama.cpp for uncommon devices/platforms with GitHub Actions, check [releases](https://github.com/PANCHO7532/personal-llamacpp-builds/releases) for prebuilt binaries.

## When is a new build/rebuild released?
Unfortunately GitHub actions isn't entirely free and due to how the workflows are designed, it's quite time consuming to consistently build llama.cpp every day for this amount of platforms. So, I'll be running the workflow whenever I remember this repository exists, or at least one time per week, if you're really desperate for a more up-to-date build, open an issue and ask me to run the workflow

## Builds currently being made
- Windows XP x86/x64, CPU only
- Android armv7l and armv8a targeting Android API 21 (5.0 Lollipop), CPU only

## Planned builds
